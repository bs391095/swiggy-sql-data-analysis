# Swiggy SQL Data Analysis

## Project Overview

In this project, I analyzed a Swiggy relational dataset using SQL to understand customer activity, restaurant performance, orders, and delivery partner activity.

The dataset contains multiple tables related to customers, restaurants, orders, and delivery partners. I used SQL queries to connect and analyze these tables and answer different business-related questions.

The main purpose of this project was to practice SQL for data analysis and understand how SQL can be used to extract useful information from relational business data.

## Objective

The objectives of this project were to:

- Analyze customer activity and ordering behavior
- Understand restaurant performance
- Calculate customer order counts
- Analyze restaurant revenue
- Identify highly rated restaurants
- Identify inactive customers
- Analyze recent orders
- Understand delivery partner activity
- Explore customer and restaurant ordering patterns

## Dataset

The dataset contains five core tables representing different parts of the food delivery process.

### Customers

Contains customer information such as:

- Customer ID
- Customer name
- City
- Contact details

### Restaurants

Contains information such as:

- Restaurant ID
- Restaurant name
- City
- Ratings

### Orders

Contains order records connecting customers, restaurants, and dates.

### Delivery Partners

Contains delivery partner information and delivery completion records.

## SQL Analysis

### 1. Customer Analysis by Location

Identified customers who live in Delhi.

This can help analyze customers within a specific region and support location-based marketing analysis.

### 2. Restaurant Rating Analysis

Calculated the average rating of restaurants in Mumbai.

This helps understand restaurant performance and customer satisfaction within the Mumbai market.

### 3. Active Customers Report

Identified customers who have placed at least one order.

This helps distinguish active customers from customers who have not yet used the platform.

### 4. Customer Order Count Analysis

Calculated the total number of orders placed by each customer.

This helps understand customer ordering frequency.

### 5. Restaurant Revenue Analysis

Calculated the total revenue generated by each restaurant.

This helps analyze restaurant-level sales performance.

### 6. Top Rated Restaurants

Identified the top 5 restaurants based on average rating.

This provides a way to analyze highly rated restaurants in the dataset.

### 7. Inactive Customers Report

Identified customers who have never placed an order.

This can be useful for understanding inactive customers.

### 8. Mumbai Customer Order Analysis

Calculated the number of orders placed by each customer in Mumbai.

This helps analyze ordering behavior within a specific city.

### 9. Recent Orders Analysis

Identified orders placed during the last 30 days.

This helps analyze recent order activity in the dataset.

### 10. Delivery Partner Performance

Identified delivery partners who completed more than one delivery.

This provides an overview of active delivery partners.

### 11. Customer Ordering Pattern

Identified customers who placed orders on exactly three different days.

This helps analyze repeat ordering behavior.

### 12. Top Delivery Partner Analysis

Identified the delivery partner who worked with the highest number of different customers.

This helps analyze delivery partner reach across customers.

### 13. Customer and Restaurant Matching Analysis

Identified customers from the same city who ordered from the same restaurants on different dates.

This helps explore customer preferences and regional ordering patterns.
